I needed to create paths, with cooridnates on a given SVG so I could have another tool create animations form them.   This is the result of what I needed to create.

- Load BG
- Click the Path you want
- Hold Space Bar and Drag if you need to
- Click "Copy" to save that Path
- Click "Clear" to make new Path
- Repeat

This is a speiclized tool for creating paths on SVG files - however, it might be useful for CNC routing, Laser engraving and ed printing because they all work with SVGs too.
